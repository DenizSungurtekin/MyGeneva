# Screens.md — Écrans du MVP

## 1. Écran d'accueil
- Navigation par jour (calendrier jour par jour), "aujourd'hui" sélectionné par défaut
- Accès aux 3 catégories : Journée / Soirée / Restaurant

## 2. Liste des events/restaurants (pour un jour donné)
- Carte par item avec : titre, lieu, horaire (events) ou note Google (restaurants), image
- Défilement (scroll) comme mode de découverte principal — pas de recherche prévue

## 3. Détail d'un item
- Description complète
- Localisation sur carte
- Bouton "ajouter aux favoris"

## 4. Écran Favoris
- Liste des items mis en favori (events + restaurants), stockés via `user_id` hardcodé (pas d'authentification au MVP)
